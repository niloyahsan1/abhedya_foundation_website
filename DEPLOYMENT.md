# ABHEDYA FOUNDATION — PRODUCTION DEPLOYMENT & MAINTENANCE GUIDE

**Website Domain:** [https://abhedyafoundation.org](https://abhedyafoundation.org)  
**Backend Framework:** Laravel 13.x (PHP 8.3+)  
**Database:** MySQL 8.0+  
**Administrative Dashboard:** Tyro Dashboard (`hasinhayder/tyro-dashboard`)  
**Frontend Assets:** Laravel Blade, Tailwind CSS v4, Alpine.js, Vite  

---

## 1. System Requirements

* **PHP:** >= 8.2 (PHP 8.3 recommended)
  * Extensions required: `bcmath`, `ctype`, `curl`, `dom`, `fileinfo`, `filter`, `gd` (or `imagick`), `json`, `mbstring`, `openssl`, `pcre`, `pdo_mysql`, `tokenizer`, `xml`, `zip`.
* **Database:** MySQL >= 8.0 or MariaDB >= 10.4 (InnoDB engine, `utf8mb4_unicode_ci`).
* **Web Server:** Nginx or Apache (with `mod_rewrite` enabled).
* **Node.js & npm:** Node >= 20.x, npm >= 10.x (for building frontend assets).
* **Composer:** Composer >= 2.6.

## 2. Fresh Installation Steps

### Step 1: Clone and Configure Environment
```bash
git clone https://github.com/niloyahsan1/abhedya_foundation_website.git /path/to/project
cd /path/to/project

cp .env.example .env
```

Edit `.env` to configure your production database credentials and application URL:
```env
APP_NAME="Abhedya Foundation"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://abhedyafoundation.org

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=abhedya_foundation
DB_USERNAME=your_database_user
DB_PASSWORD=your_secure_password
```

### Step 2: Install Dependencies
```bash
# Install PHP dependencies without dev packages in production
composer install --no-dev --optimize-autoloader

# Install Node dependencies and compile production assets
npm ci
npm run build
```

### Step 3: Key Generation & Storage Link
```bash
php artisan key:generate --force
php artisan storage:link
```

### Step 4: Run Migrations and Seeders
```bash
# Run migrations in production
php artisan migrate --force

# Seed foundation settings, categories, tags, projects, and initial admin
php artisan db:seed --force
```

## 3. Initial Administrator Access & RBAC

### Default Super-Admin Credentials (Generated by Seeder)
* **Login URL:** `https://abhedyafoundation.org/login`
* **Admin Dashboard:** `https://abhedyafoundation.org/dashboard`
* **Email:** `admin@tyro.project`
* **Password:** Seeded with standard admin credentials.

> [!IMPORTANT]
> **Action Required Immediately After First Login:**
> 1. Log in at `/login`.
> 2. Navigate to **My Profile** -> Change password to a strong, high-entropy credential.
> 3. Go to **Administration -> Users** to create individual team accounts with appropriate roles (`admin` or `editor`).

### Role-Based Access Control (RBAC) Boundaries
* **`admin` / `super-admin`:** Full administrative rights, including managing users, updating site settings, configuring SMTP, viewing audit logs, and verifying/rejecting financial donation records.
* **`editor`:** Content publication access (Blog Posts, Projects, Campaigns, Campaign Updates, Gallery Albums). Editors have **read-only** visibility on donation records and cannot verify financial transactions or alter system credentials.
* **`public`:** Unauthenticated visitors can only browse public pages and submit donation/contact records (which are saved in `pending` status).

## 4. cPanel Deployment Configuration

### Safe Document Root Configuration
On cPanel hosting, Laravel's core code **must never be accessible directly via the web root**.

1. **Recommended Method (Subdomain or Primary Domain Root):**
   * Place the entire application outside `public_html` (e.g., in `/home/username/abhedya_app`).
   * In cPanel -> **Domains**, set the Document Root for `abhedyafoundation.org` to:
     ```
     /home/username/abhedya_app/public
     ```

2. **Alternative Method (If primary document root is fixed to `public_html`):**
   * Upload all application folders (`app`, `bootstrap`, `config`, `database`, `vendor`, etc.) to `/home/username/abhedya_core`.
   * Upload the contents of Laravel's `public/` directory directly into `/home/username/public_html`.
   * In `/home/username/public_html/index.php`, adjust paths to reference the parent core:
     ```php
     require __DIR__.'/../abhedya_core/vendor/autoload.php';
     $app = require_once __DIR__.'/../abhedya_core/bootstrap/app.php';
     ```

### Directory Permissions
Ensure write permissions for the web server user (`chmod -R 775`):
```bash
chmod -R 775 storage bootstrap/cache
```

## 5. Performance Optimization & Caching Commands

```bash
php artisan config:cache

```

```bash
php artisan optimize:clear

```

## 6. Maintenance & Backup Recommendations

### Automated Database Backups
Schedule daily MySQL dumps via cron:
```bash
0 2 * * * mysqldump -u your_user -p'your_password' abhedya_foundation | gzip > /home/username/backups/db_$(date +\%F).sql.gz
```
Retain backup archives for at least 30 days.

### Audit Trails
Tyro Dashboard records important administrative actions in the `tyro_audit_logs` table. Periodically review recent logs at:
```
https://abhedyafoundation.org/dashboard/audits
```
